# ลอยกระทงออนไลน์ 🪷

เว็บลอยกระทงออนไลน์ เลือกแบบกระทง กรอกชื่อ และพิมพ์คำอธิษฐานให้ลอยไปตามสายน้ำ
สร้างด้วย HTML / CSS / JavaScript และใช้ Node.js เป็นเซิร์ฟเวอร์ทดสอบในเครื่อง

## ฟีเจอร์
- เลือกแบบกระทง 4 แบบ (ดอกบัว, ดาวเรือง, อัญชัน, ใบตอง)
- กรอกชื่อ (ไม่เกิน 20 ตัวอักษร) และคำอธิษฐาน (ไม่เกิน 80 ตัวอักษร)
- กระทงลอยบนแม่น้ำพร้อมเปลวเทียนและแอนิเมชัน แตะ/เอาเมาส์ชี้เพื่ออ่านคำอธิษฐาน
- บันทึกจำนวนกระทงและคำอธิษฐานล่าสุดในเบราว์เซอร์ (localStorage)

## รันในเครื่อง
```bash
node server.js
# เปิด http://localhost:3000
```
(ต้องติดตั้ง Node.js เวอร์ชัน 16 ขึ้นไป)

## Deploy บน GitHub Pages
1. Push โค้ดขึ้น GitHub repository
2. ไปที่ Settings → Pages
3. Source: Deploy from a branch → Branch: `main` / โฟลเดอร์ `/docs` → Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## โครงสร้างโปรเจกต์
```
├── docs/            ไฟล์เว็บ (GitHub Pages อ่านจากโฟลเดอร์นี้)
│   ├── index.html
│   ├── style.css
│   └── script.js
├── server.js        เซิร์ฟเวอร์ Node.js สำหรับทดสอบ
├── package.json
└── README.md
```
